diag-lite 体检工具 v0.7.1 —— 使用说明（五树体检 + 全面体检 + 图形版）
==========================================

【这是什么】
一个免费的 Windows 体检小工具，七个入口：
1. 网络体检.bat——上不了网、网页打不开时用：从"网卡→路由器→公网→域名解析"
   四层逐层检查，报告告诉你断点在哪一层、证据是什么、怎么修。
2. 蓝屏体检.bat——电脑蓝屏过、想查原因时用：查近 90 天蓝屏记录、掉电死机、
   硬件报错、已知嫌疑驱动，报告给出"隐患结论"（蓝屏码人话翻译+修复方向）。
3. 硬件体检.bat——想给电脑做硬件年检时用：查磁盘健康、SMART 预警、电池损耗、
   过热、内存诊断史、硬件报错（WHEA），报告按"存储→供电散热→内存主板"三层给出
   隐患结论。部分项目查不到会标"跳过"（家用盘/台式机常见=不是没查到问题，
   是这台机器不向 Windows 暴露该数据）。
4. 性能体检.bat——电脑开机慢、用着卡时用：查官方开机时长记录、拖后腿点名名单、
   自启清单、服务超时史、磁盘水位、内存压力、磁盘 IO 堵塞，报告按
   "开机慢→启动负担→卡顿现场"三层给出性能瓶颈结论。开机记录类查询需要管理员
   权限的机器会标"跳过"（管理员身份重跑可复核）。
5. 驱动体检.bat——怀疑驱动来路不正、设备管理器有黄三角时用：查在跑驱动的签名、
   古董驱动（Win7 时代老驱动）、第三方驱动体量、网络过滤链叠加、设备错误码、
   驱动加载失败史、已知嫌疑驱动（如给梨加速器捆绑驱动），报告按
   "签名与年代→叠加体量→点名证据"三层给出驱动隐患结论。
6. 全面体检.bat——不知道哪里有问题、想一次查全时用：弹出中文菜单，
   直接回车=连跑上面五树出一份合并报告（带五树总览表，约几分钟）；
   或输入数字 1-5 只跑其中一项。
7. 全面体检（图形版）.bat——同上，但是窗口界面（推荐）：双击后黑色窗口一闪
   即消，弹出「diag 电脑体检台」深色窗口；勾选要查的项目（默认全面体检）、
   点「开始体检」看实时进度，跑完左侧出结果树，FAIL 项可一键复制修复建议；
   也可点「浏览器看完整报告」看网页版。窗口程序与命令行版查的东西完全一样。

【放心声明（重要）】
本工具全程"只读体检"——只查看电脑状态，绝不会修改你的任何设置。
报告里给的修复命令也是让你自己复制、看懂了再手动执行，工具不会替你执行。

【怎么用】
1. 把整个文件夹解压到任意位置（桌面也行），不要删里面的 engine、checks、trees、gui 文件夹。
2. 双击「全面体检（图形版）.bat」出窗口界面（推荐）；或双击「网络体检.bat」
   「蓝屏体检.bat」「硬件体检.bat」「性能体检.bat」「驱动体检.bat」任一个，
   会弹出黑窗口自动检查，一般 1~3 分钟；双击「全面体检.bat」先出菜单，
   回车跑全部（几分钟）或按数字 1-5 跑单项。
3. 跑完后报告会自动用浏览器打开（网页样式，带配色、证据可折叠）；没弹的话，
   去 reports 文件夹找最新的 .html 文件，双击打开。
4. reports 文件夹最多保留最新 50 份报告，旧报告会自动清理，重要结论请自己另存。

【报告怎么看】
- 「断点结论」/「隐患结论」：问题出在哪，一句大白话。
- 「修复建议」：给了命令的，复制到开始菜单搜 cmd 打开的黑窗口里执行（先看清内容）；
  让你重启路由器/检查网线/卸载软件的，按提示做。
- 「证据链」：每条结论后面的原始数据（默认收起，点层标题展开）；截图发群里求助时带上它最有用。

【常见问题】
- 双击后 Windows 蓝色弹窗提示"已保护你的电脑"？
  这是 Windows 对无签名脚本的通用提醒（本工具没有花钱买签名）。
  点「更多信息」→「仍要运行」即可。
- 杀毒软件报毒？本工具只有只读检查命令（netsh/ping/nslookup/Get-WinEvent 等），
  属于误报，添加信任或放行即可；不放心就别用，诊断也可以手动做。
- 要求：Windows 10/11，无需安装任何东西。
