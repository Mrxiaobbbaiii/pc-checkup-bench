电脑体检台 v1.7.0 —— 使用说明（六类体检 + 全面体检 + 网页版）
==========================================

【这是什么】
一个免费的 Windows 体检小工具，九个入口：
1. 网络体检.bat——上不了网、网页打不开时用：从"网卡→路由器→公网→域名解析"
   分四层逐项检查，报告告诉你问题出在哪一环、证据是什么、怎么修。
2. 蓝屏体检.bat——电脑蓝屏过、想查原因时用：查近 90 天蓝屏记录、掉电死机、
   硬件报错、已知嫌疑驱动，报告给出"隐患结论"（蓝屏码人话翻译+修复方向）。
3. 硬件体检.bat——想给电脑做硬件年检时用：查磁盘健康、SMART 预警、电池损耗、
   过热、内存诊断史、硬件报错（WHEA），报告按"存储→供电散热→内存主板"三层给出
   隐患结论。部分项目查不到会标"跳过"（家用盘/台式机常见=不是没查到问题，
   是这台机器不向 Windows 暴露该数据）。
4. 性能体检.bat——电脑开机慢、用着卡时用：查官方开机时长记录、拖后腿点名名单、
   自启清单、服务超时史、磁盘水位、内存压力、磁盘 IO 堵塞，报告按
   "开机慢→启动负担→卡顿现场"三层给出性能瓶颈结论。开机记录类查询需要管理员
   权限的机器会标"跳过"（管理员身份重跑可复核）。
5. 驱动体检.bat——怀疑驱动来路不正、设备管理器有黄三角时用：查在跑驱动的签名、
   古董驱动（Win7 时代老驱动）、第三方驱动体量、网络过滤链叠加、设备错误码、
   驱动加载失败史、已知嫌疑驱动（如加速器捆绑驱动），报告按
   "签名与年代→叠加体量→点名证据"三层给出驱动隐患结论。
6. 安全体检.bat——想给电脑做安全年检时用：查微软 Defender 杀毒防护（防护开关/
   防护服务/近 30 天检出史/查杀排除项）和系统加固（UAC 档位/防火墙/磁盘加密/
   可疑计划任务），报告按"防病毒→系统加固"两层给出安全结论。部分项目查不到会标
   "跳过"（如排除项内容和磁盘加密状态要管理员权限才看得到=不是没问题，是看不到，
   报告里给了人工核对入口）。
7. 全面体检.bat——不知道哪里有问题、想一次查全时用：弹出中文菜单，
   直接回车=连跑上面六类出一份合并报告（带六类总览表，约几分钟）；
   或输入数字 1-6 只跑其中一项。
8. 全面体检（网页版）.bat——新一代窗口界面（推荐）：双击后弹出
   「电脑体检台」独立窗口（深色科技感，右上角可换主题颜色）。三个页签：
   体检向导（勾选+进度+日志）/结果中心（结果树+详情+复制）/修复中心（查出的
   问题清单：绿色小修可一键代跑，黄色逐项确认后代跑，红色给分步指南）。
   需要电脑上有 Edge 浏览器（Windows 10/11 一般自带）。
   两个窗口入口查的东西完全一样，界面新旧不同。

【放心声明（重要）】
本工具体检全程只读，只看不动。只有你进修复中心、亲自点「执行」，工具才会动手：
绿色=完全可逆的小修（代跑+自动复查）；黄色=先生成撤销包、你逐项确认才跑；
红色=永远只给步骤，工具绝不代跑。

【怎么用】
1. 把整个文件夹解压到任意位置（桌面也行），不要删里面的 engine、checks、trees、ui 文件夹。
2. 双击「全面体检（网页版）.bat」出窗口界面（推荐）；或双击「网络体检.bat」
   「蓝屏体检.bat」「硬件体检.bat」「性能体检.bat」「驱动体检.bat」「安全体检.bat」
   任一个，会弹出黑窗口自动检查，一般 1~3 分钟；双击「全面体检.bat」先出菜单，
   回车跑全部（几分钟）或按数字 1-6 跑单项。
3. 跑完后报告会自动用浏览器打开（网页样式，带配色、证据可折叠）；没弹的话，
   去 reports 文件夹找最新的 .html 文件，双击打开。
4. reports 文件夹最多保留最新 50 份报告，旧报告会自动清理，重要结论请自己另存。

【报告怎么看】
- 「上网问题结论」/「隐患结论」：问题出在哪，一句大白话。
- 「修复建议」：给了命令的，复制到开始菜单搜 cmd 打开的黑窗口里执行（先看清内容）；
  让你重启路由器/检查网线/卸载软件的，按提示做。
- 「证据链」：每条结论后面的原始数据（默认收起，点层标题展开）；截图发给懂电脑的人求助时带上它最有用。

【常见问题】
- 双击后 Windows 蓝色弹窗提示"已保护你的电脑"？
  这是 Windows 对无签名脚本的通用提醒（本工具没有花钱买签名）。
  点「更多信息」→「仍要运行」即可。
- 杀毒软件报毒？本工具只有只读检查命令（netsh/ping/nslookup/Get-WinEvent 等），
  属于误报，添加信任或放行即可；不放心就别用，诊断也可以手动做。
- 要求：Windows 10/11，无需安装任何东西。

【setup.exe 安装版】
- 拿到「PC-CheckupBench-setup-v1.7.0.exe」双击安装：免管理员，装到自己的用户目录，
  桌面和开始菜单出现「电脑体检台」图标。
- 双击图标打开的是原生窗口（不是浏览器页面），关窗即完全退出，不留后台进程。
- 卸载走「设置 → 应用」或安装目录里的 unins000.exe：卸载前会自动把你的体检
  报告、修复记录备份到旁边的「电脑体检台-报告备份-<日期>」文件夹，不会丢。
- 装了安装版就不用再解压 zip 版；两者装到同一个目录，装其一即可。

【一键安装 / 卸载】
不想解压后到处找文件夹？解压一次，以后双击「一键安装.bat」：
1. 右键 zip 解压到任意文件夹（如桌面），双击「一键安装.bat」按 Y——
   程序装到 C:\Users\你的用户名\AppData\Local\电脑体检台，不需要管理员。
2. 以后从安装文件夹里双击「全面体检.bat」用即可；升级=解压新版再点一次安装（覆盖升级，
   你加的自定义检查和历史报告都会保留）。
3. 卸载=双击「一键卸载.bat」：会先问你 ext 自定义检查和历史报告留不留（推荐保留，
   留下的备份在「电脑体检台-ext备份 / 电脑体检台-reports备份」两个文件夹，不要了手动删）。

【加自己的检查（ext 扩展口子）】
装好（或解压）目录里有个 ext 文件夹：把你自己的检查脚本放 ext\checks、体检树放
ext\trees、修复指南放 ext\repair\actions，重启网页版就能用，不用重新打包。
怎么写？照 ext\示例\ 里的三个现成例子改，ext\README.txt 有三步说明。网页版树选择
器里会多出你的「扩展树」——它不属于「全面体检」，单独勾选单跑。
